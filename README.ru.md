# DiffShield 🛡️

**Проверяйте изменения Pull Request на распространённые риски безопасности до слияния.** DiffShield — бесплатное GitHub-действие без внешних зависимостей. Оно анализирует только Git diff двух коммитов и публикует понятный отчёт в GitHub Actions.

- Ищет известные форматы токенов и похожие на секреты присваивания в добавленных строках. Значения секретов не попадают в логи, аннотации, сводку или JSON-отчёт.
- Предупреждает об изменённых файлах `.env`, ключах и файлах учётных данных.
- Проверяет новые workflow GitHub Actions: чрезмерные права токена, неприкреплённые к SHA сторонние действия, вставку текста PR напрямую в `run:` (включая многострочные команды) и рискованные ссылки `pull_request_target`.
- Отмечает изменения файлов блокировки зависимостей.
- Создаёт аннотации с путями и строками, эвристическую оценку 0–100 и файл `diffshield-report.json`.
- Работает на GitHub runner с Node.js, не требует API-ключа, платного сервиса, сетевого обращения или установки npm-пакетов.

> DiffShield помогает при проверке кода, но не заменяет аудит безопасности. Оценка — эвристика, не вероятность и не сертификат безопасности. Поиск секретов по шаблонам может что-то пропустить или отметить учебный пример. Если секрет мог попасть в репозиторий, отзовите его и смените.

## Подключение

Создайте `.github/workflows/diffshield.yml`:

```yaml
name: DiffShield
on:
  pull_request:
permissions:
  contents: read
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - name: Check out source
        uses: actions/checkout@11d5960a326750d5838078e36cf38b85af677262 # refs/tags/v4
        with:
          fetch-depth: 0
          persist-credentials: false
      - name: Analyze pull request changes
        uses: GhosTnever-lkm/diffshield-action@ed6c7eedef8c77df131b03518f91c678a0c5686b # v1.0.0
        with:
          base-sha: ${{ github.event.pull_request.base.sha }}
          head-sha: ${{ github.event.pull_request.head.sha }}
          fail-on: high
```

Для workflow с высокими требованиями к безопасности после проверки релиза укажите полный SHA коммита самого DiffShield. Пример `@v1` короче, но тег можно переместить. Не выдавайте секреты репозитория workflow, который запускается для внешних pull request.

| Параметр | Обязательный | По умолчанию | Значение |
|---|---:|---:|---|
| `base-sha` | да | — | Полный SHA базового коммита (40 символов) |
| `head-sha` | да | — | Полный SHA проверяемого коммита (40 символов) |
| `fail-on` | нет | `high` | Порог завершения с ошибкой: `critical`, `high`, `medium`, `none` |
| `max-findings` | нет | `100` | Сколько замечаний показывать в сводке (1–1000); JSON содержит все |

Выходы: `risk-score`, `findings-count`. Сводка видна в запуске Actions. `diffshield-report.json` сохраняется в рабочей папке, поэтому последующие шаги могут загрузить его как артефакт.

## Разработка

Нужны Node.js 20+ и Git. Установка npm-пакетов не требуется.

```powershell
node --test test/scan.test.mjs
```

## Что проверяется

Шаблоны ищут заголовки приватных ключей, распространённые токены GitHub/AWS/Google/Slack/Stripe, bearer-токены и присваивания имён вроде `password`, `secret`, `api_key`, `access_token`. Фильтруются заглушки вроде `YOUR_API_KEY` и `change_me`. Проверяются добавленные строки diff, а не вся история репозитория. Для поиска секретов, закоммиченных раньше, используйте отдельное средство проверки истории.

Анализ workflow консервативный и построчный, без полноценного YAML-парсера. Проверяйте контекст каждого предупреждения. DiffShield не меняет файлы, не пишет комментарии и не запрашивает права на запись.
